# Glossary

Local terms of art, so nobody has to guess.

| Term | Meaning |
| --- | --- |
| **Pellet Index** | The club's in-house fantasy-football-style performance competition. Players accumulate points across a season for appearances, goals, assists, clean sheets, saves and so on, plus 3/2/1 bonus points from a post-match vote. Running since 2023/24 |
| **WWFC** | Westminster Wanderers FC |
| **SSFL** | Southern Sunday Football League. The club's league, covering Southwark, Lambeth, Wandsworth and Merton |
| **Full-Time** | FA Full-Time, the FA's fixture and results platform for grassroots leagues. `fulltime.thefa.com` |
| **Def Inf** | ✅ Confirmed: a deliberate flat +1 point for a GK or DF who plays 60+ minutes, added to compensate for how hard clean sheets are in Sunday league. Not a tackles/interceptions count. Zero if under 60 minutes — no partial credit — see **Q3/Q4** |
| **C/Sheet** | Clean sheet. Worth 8 to a GK or DF, 4 to a midfielder, 2 to a forward. **Confirmed: zero if the player was on for under 60 minutes** (a hard gate, not a halving). **From 2026/27**, also tiered by goals conceded while on (for players who did play 60+): 0 conceded = full, 1 conceded = half (new), 2+ = zero — see **Q4** |
| **Bonus** | The 3/2/1 points awarded to the top three players in the post-match team vote |
| **PPG** | Points per game — Pellet Index total divided by appearances. Added to the spreadsheet in 2025/26 |
| **FPL** | A column in the sheets equal to the Pellet total multiplied by a fixed factor (1.5 in 23/24, 1.3 since). ✅ Confirmed purpose: not a real multiplier, an approximation of "which real Fantasy Premier League player has a similar points total, scaled for a ~20 vs. 38-game season." Confirmed non-MVP, not being built |
| **Drop out / no show** | A −5 penalty, but ✅ confirmed it's about **communication, not timing**: telling the Manager you can't play, even on the morning of the match, is fine. It only applies to genuine silence — not showing up and not telling anyone. Was −2 in 23/24 |
| **Ruleset** | A versioned, season-scoped set of scoring values. Each season has its own; historical seasons keep theirs permanently. ✅ Confirmed immutable once a season starts — no mid-season rule changes |
| **Appearance** | A player's involvement in one specific match: the position they played, their role (started / substitute / unused / no-show), and whether they reached the 60-minute mark (`played60`) — never an exact minute count, that data doesn't exist for this club |
| **Graham Dodd Premier Division** | The SSFL's top division, sponsored by Supreme Trophies. Westminster Wanderers' division for 2026/27 |
| **Tony Eldridge Championship** | The SSFL's second tier. Westminster Wanderers finished second in 2024/25 |
| **Scorer** | The person who maintains the Pellet Index data. Historically the spreadsheet owner |
| **MLIP / CC / FBC** | The three cup competitions Westminster Wanderers actually enter and which count toward the Pellet Index (roughly 3, 1 and 2 games a season respectively). Friendlies and tour games don't count |
| **Kit** | ✅ Confirmed: not a bug. A deliberate +1 point in 2025/26 for whoever washed the club kit that week, to spread the chore around. Folded into that season's `Total`. **Retired for 2026/27** — kit washing is now drawn from a hat, no points attached |
| **Match fee** | New for the app (not in the legacy sheets): £12 owed for playing 60+ minutes, £6 for less. Tracked per appearance, replacing the old `Yearly Subs` column, which is dropped entirely |
| **Stack** | The existing tool the club already uses to track player availability ahead of a match. Not being replaced by this app |
